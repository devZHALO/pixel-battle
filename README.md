# Pixel Battle

Локальный прототип пиксель-арт баттла: холст 500×500, авторизация по никнейму
и паролю, 32 цвета, кулдаун 1 минута (кроме пользователя `oguricappu`),
совместное рисование в реальном времени через WebSocket. Работает на
десктопе (мышь) и на телефоне (тач, пинч-зум).

## Требования

- Node.js версии 18 или новее (проверить: `node --version`)

## Запуск

```bash
cd pixel-battle
npm install
npm start
```

Откройте в браузере: **http://localhost:3000**

Чтобы проверить "баттл", откройте адрес в двух вкладках (или на двух
устройствах в одной сети) под разными аккаунтами — пиксели будут
появляться друг у друга мгновенно.

## Как это работает

- **Регистрация/вход** — никнейм (3–20 символов, буквы/цифры/`_`) и пароль
  (от 4 символов). Пароли хранятся хешированными (bcrypt). При регистрации
  нужно отметить два чекбокса — согласие с Условиями использования и
  Политикой конфиденциальности (текст открывается по клику в модальном окне);
  без обоих согласий кнопка регистрации неактивна, сервер тоже это проверяет.
- **Условия использования** запрещают: флаги любых государств/организаций,
  нацистскую и экстремистскую символику, откровенный NSFW-контент (купальники
  — можно, откровенные сцены — нет), мат и оскорбления, мультиаккаунтинг.
  Администрация вправе удалять или изменять любые пиксели без объяснения
  причин.
- **Граница холста** — вокруг полотна нейтральный фон (`#34313f`), которого
  нет в палитре, плюс тонкая рамка по краю холста, чтобы чёрные (и любые
  другие) пиксели на границе не сливались с фоном.
- **Без кулдауна** — если войти под никнеймом `oguricappu` (регистр не
  важен), кулдаун не применяется (в интерфейсе отмечено значком ★).
  Остальным пользователям — 60 секунд между пикселями, сервер это
  отслеживает независимо от клиента.
- **Подсветка наведения** — пиксель под курсором/пальцем подсвечивается
  серым перед постановкой, чтобы не промахиваться.
- **Управление холстом** (как в wplace):
  - мышь: зажать и потянуть левой кнопкой — панорамирование; колесо — зум
    к курсору; клик (без перетаскивания) — поставить пиксель;
  - телефон/планшет: один палец — панорамирование и тап для постановки
    пикселя; два пальца — пинч-зум;
  - кнопки `+` / `−` / `⤢` внизу справа — зум и подгонка по экрану.
- **Скачать карту** — кнопка `⬇` рядом с зумом сохраняет текущий холст как
  PNG-файл 500×500 (по одному пикселю картинки на один пиксель холста).
- **Палитра** — 32 цвета (набор в духе r/place), выбор в горизонтально
  прокручиваемой полосе внизу; текущий выбранный цвет всегда виден отдельным
  квадратом слева от палитры.
- **Данные** сохраняются в папке `data/`:
  - `data/users.json` — аккаунты;
  - `data/canvas.bin` — 250 000 байт, по одному на пиксель (0 = пусто/`#ffffff`,
    1–32 = индекс цвета). Удалите файлы в `data/`, чтобы начать заново.

## Важно для теста

- Сессии и кулдауны пользователей хранятся в памяти процесса — при
  перезапуске сервера (`npm start`) кулдауны сбрасываются, а холст и
  аккаунты сохраняются на диске.
- Секрет сессии в `server.js` захардкожен для удобства локального теста —
  для публичного развёртывания замените его на случайную строку и
  используйте HTTPS.
- Порт можно изменить переменной окружения `PORT`, например:
  `PORT=8080 npm start`.
